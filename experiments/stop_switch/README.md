# L0 V5 动作中途停止试验

部署仿真验证了双脚支撑的上身收势，独立 MuJoCo 试验比较了单脚与双脚支撑时的处理方法。两者使用同一份 AMP1124 和同一个碰撞模型。本轮没有训练模型。正式仿真的启动、按停和急停命令见[部署操作说明](../../src/l0_ros2_deploy_v2/docs/sim2mujoco-deployment.md#运行中途软停止)。

## 正式 sim2mujoco 在线交接

在 Sonic800 停止试验入口，14 条全身参考已用同一个 Base 在独立 MuJoCo 中完成自然播放与中点按停对照。逐条记录给出按停帧、收势起点与交接结果。[14 个动作对照](l0_v5_amp_1124/sonic73983_motion_stops.json)

长动作示例为 `stand_random_upper_120s`。交付包 Sonic800 73983 Base 播放已有的 6000 帧随机动作，第 1343 帧开始收势，第 1377 帧通过交接检查。按停后约 3 秒，左肩侧抬角已收回约 56°，恢复到 AMP 实测站姿。[长动作关节与支撑记录](l0_v5_amp_1124/stand_random_upper_120s_handoff.json)

使用安装后的 ROS 2 启动入口和 `mujoco_control` 命令，先让 `A-C04_mod` 自然完成，再次播放时中途发 `soft-stop`。跟踪端为部署包内的 WBC10000 + 该动作的 LoRA，AMP 为默认 AMP1124。试验节点从仿真 PD 读取实际生效的目标，从地面接触约束读取左右脚法向力。软停止按当前 WBC 交接编号生效，原来的紧急阻尼通路继续可用。[在线录包测量](l0_v5_amp_1124/ros_handoff.json)

最终复测在第 95 帧开始收势，第 129 帧满足连续五拍的交接条件。实测 AMP 第一拍与此前仿真 PD 使用的目标相比，腿部最大差为 0.272 rad，上身为 0.120 rad。0.35 s 过渡结束后的 2.998 s 内，AMP 独立输出 150 拍，1499 个物理采样点均为双脚受力，最大水平速度为 0.0193 m/s。进入 Walking 时桥接器短暂报告等待策略命令，结束录包、关闭仿真时报告模拟电机禁用确认超时。

用一次自然完成播放的实测观测与初始 AMP 目标，分别调用 `f9f6e37` 和试验版本源码中的 C++ `makeCommandInput`，输入同一份原始逐帧参考，分别滚动动作历史并用同一组部署 Base、LoRA 参数做 ONNX Runtime 推理。回放包含起始保持 50 拍和整条动作 460 拍，240 维指令与 21 维动作的最大绝对差均为 0。这项比较固定了传感器样本，独立于两次 ROS 进程启动的时序差异。[C++ 编码回放](l0_v5_amp_1124/no_stop_replay.json)

## PartyMimic 确定性对照

跟踪策略采用动作资产包的 PartyMimic 260000。挥手来自 219 帧的 `wave_R_001__A428`，舞蹈来自 966 帧的 `L0_billiejean_A`。独立仿真从各自参考第 0 帧、零速度开始，使用部署场景、0.002 s 物理步长、0.02 s 策略周期及部署 AMP 的站姿、增益和交接历史初始化。物理引擎为 MuJoCo 3.7.0，推理为 ONNX Runtime CPU。没有添加噪声。AMP 接管采用 0.35 s 目标和增益过渡，之后继续跑 3 s。持续检查跌倒，最后 1 s 每拍检查双脚受力、水平速度、角速度和倾角。

| 试验 | 按停参考帧（从 0 开始） | 结果 |
|---|---|---|
| 原始挥手，冻结当前腿姿，收回上身 | 63、100、176 | 前两次保持 WBC，3 s 等待期内腿部目标差最低仍为 1.198、1.160 rad。第 176 帧按停后，AMP 接管并站稳。|
| 同一挥手上身，整段使用实测 AMP 腿姿和骨盆 | 54、100、166 | 三次均站稳。第 100 帧按停，第 134 帧开始交接。|
| 舞蹈，在当前支撑相位直接向全身站姿补间 | 139 左脚、114 右脚、110 双脚 | 三次均接管并站稳。|
| 同三次请求，保留原舞蹈至第 148 帧再做相同全身补间 | 同上 | 三次均接管并站稳。|
| 同三次请求，仅收上身并冻结腿姿 | 同上 | 当拍冻结、到第 148 帧冻结、到第 151 帧冻结，九次都在 3 s 等待期内未通过交接检查。|

上身补间以当前上身参考角、相邻帧估算的初始速度、AMP 实测终点和零末速构造三次 Hermite 曲线。全身对照同时插值腿部关节和骨盆高度、倾角，保留起点平面位置与航向。双脚各自与地面的法向力超过 2 N 才标记双支撑。腿部目标差 0.45 rad、上身 1.5 rad 等均为本轮试验阈值。AMP 预推理在每个候选交接拍重建首拍观测，复用部署端交接时重复填满五帧历史的约定。

左、右、双脚标签来自原始播放时测得的接触力。第 148 帧是相应按停时刻之后，基准轨迹第一次连续五拍满足支撑和基座运动条件的起点。第 151 帧另考虑与 AMP 腿姿的距离。这两个落点使用基准轨迹事后选择，代表已知动作片段的对照。实验只覆盖这一条舞蹈的三个时刻。连续承重期间脚踝水平位移最高约 12 mm，其中可包含滚动和足部转动；这些数据不能证明全身补间在任意相位都不会滑脚。

未收到 STOP 的独立仿真从相同状态分别运行原取帧路径和带 STOP 分支的播放器。原始挥手 219 拍、固定腿姿挥手 219 拍、舞蹈 966 拍的 `command_short[240]` 和 `action[21]` 均逐拍完全相等。按停之前的全部输出也与相应基准逐拍相等。完整记录含关节顺序对应的交接差、各方案峰值参考速度与加速度、承重足位移及接管后的稳定性指标。[逐项结果](l0_v5_amp_1124/dynamic_trials.json)

## 复现独立试验

在工作区根目录运行。脚本只读取外部播放器、策略与动作文件，输出到指定 JSON。以下路径对应本机资产布局。

```bash
bundle="$HOME/下载/L0动作资产库_娱乐全身动作_上半身社交动作_附件 (1)"
OPENBLAS_NUM_THREADS=1 "$HOME/miniconda3/envs/active_adaption/bin/python" \
  experiments/stop_switch/validate_stop.py \
  --player "$HOME/l0_mimic-lite/projects/mimic-lite/scripts/deploy/run_l0_v2_mimic_lite_onnx_mujoco.py" \
  --policy "$bundle/sim2sim对比/policies/partymimic_260000/policy.onnx" \
  --wave "$HOME/下载/Data-partymimic/motions/soma_supplement/gesture/wave_R_001__A428.npz" \
  --dance "$bundle/npz/L0_billiejean_A.npz" \
  --output /tmp/l0-stop-trials.json
```
