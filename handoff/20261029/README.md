# L0 V5 软件更新说明

本目录说明 LoRA 共享 WBC 和板端文本动作生成相对原版本的变更、目的、涉及源码及改动规模。

- [更新说明](更新说明.md)：按加载、切换、编译、推理和 JSON 通信流程逐项说明。
- [函数级变更清单](函数级变更清单.md)：新增、修改、删除函数及行数。
- [文件级变更清单](文件级变更清单.md)：全部关联文件及统计范围。

GitHub 上可直接阅读 Markdown。下载文档包并解压后，用浏览器打开 `更新说明.html`，可展开各节函数表并跳转到原版/当前版源码行号。`audit_v2/` 保存源码对照、CSV 和 JSON 统计；`SHA256SUMS` 用于校验这些文件。

主统计基线为旧单 policy 版本到本次交付实现，共 72 个差异文件、328 个变化函数；旧文本直控清理和部署辅助脚本分别统计。本文中的本地目录、备份哈希和历史验证记录用于说明当时交付范围。包含模型的源码备份及运行依赖归档不上传到该文档目录。

日常使用仍以源码 `docs/` 下的 LoRA 部署说明和文本动作生成说明为准。
